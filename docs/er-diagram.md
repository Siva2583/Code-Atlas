# Persistence ER Diagram — Member 1 candidate v0.2

**Status:** conceptual design only. Source files in src/zccmc_data are empty placeholders; none of these entities has been activated or read in SAP. Keys and physical ABAP types need tenant verification and M2–M4 contract sign-off.

## Entity relationships

| Parent | Relationship | Child | Candidate key or constraint |
|---|---|---|---|
| SourceSystem | one to many | CustomObject | SourceSystemID; provisioned separately in the tenant |
| CustomObject | one to many | UsageFact | ObjectUUID; unique observation key is ObjectUUID + period_start + period_end + evidence_source |
| CustomObject | one to many | Finding | ObjectUUID; unique finding key is ObjectUUID + finding_id + check_id + source_reference |
| CustomObject | one to many as each endpoint | Dependency | Composite endpoint key plus dependency_type and evidence_source |
| ImportBatch | one to many | ImportRowResult | BatchUUID + source record number; append-only |
| ImportRowResult | zero or one | ImportRowError | Error details exist only for rejected rows |

## Candidate entity fields

| Entity | Candidate fields |
|---|---|
| SourceSystem | SourceSystemID |
| CustomObject | ObjectUUID; SourceSystemID; ObjectType; ObjectName; package; description; business_owner; criticality; first_seen; last_seen; findings_as_of |
| UsageFact | UsageUUID; ObjectUUID; period_start; period_end; last_executed; run_count; evidence_source; evidence_as_of |
| Finding | FindingUUID; ObjectUUID; finding_id; check_id; category; severity; message; source_reference |
| Dependency | FromObjectUUID; ToObjectUUID; dependency_type; evidence_source |
| ImportBatch | BatchUUID; file_kind; status; file_sha256; actor; created_at_utc; parsed_count; accepted_count; rejected_count |
| ImportRowResult | BatchUUID; source_record; business_key; result; row_sha256 |
| ImportRowError | BatchUUID; source_record; error_code; field_name; message |

The external CustomObject key is unique on normalized source_system + object_type + object_name; ObjectUUID is generated by persistence. SourceSystem has no import file, so it must be provisioned before object imports.

The accepted-row ledger is required for historical accepted-row provenance; the actual tenant may constrain its storage design. Existing empty placeholders include zccmc_impbatch and zccmc_improwerr. No accepted-row ledger is activated.

This diagram is not an abapGit serialization, activation claim or approved migration schema.
