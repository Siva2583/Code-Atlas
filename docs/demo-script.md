# Demo Script

## Demo objective

Show the full decision workflow for a synthetic migration portfolio: import evidence, review recommendations, and approve or override decisions with traceability.

## Demo flow

### 1. Opening the portfolio overview (2 minutes)
- Open the app on the Portfolio Overview page.
- Highlight the KPI tiles: total objects, pending review, high-risk objects, stale evidence, approved items, migrated items.
- Explain the filters: source system, package, rule-set version, risk band.
- Point out that the landing page is an executive view and not a raw technical list.

### 2. Reviewing the object inventory (3 minutes)
- Navigate to the Object Inventory list report.
- Filter to one package or source system.
- Show the columns: object name, type, package, criticality, recommended strategy, risk, status, owner, evidence as-of.
- Explain how quick filters help isolate stale evidence, high-risk objects, or rule conflicts.

### 3. Opening a decision detail (4 minutes)
- Open one object from the inventory.
- Show the header and key metadata: object name, source system, criticality, status.
- Review the usage timeline, findings summary, and dependency section.
- Explain the recommendation card with rationale, matched rules, missing evidence, rule-set version, and completeness.

### 4. Reviewing and approving/overriding a decision (3 minutes)
- Show the reviewer panel.
- Demonstrate the approve path using a sound recommendation.
- Then show the override path for a case where the reviewer intentionally changes the recommendation.
- Emphasize that a reason is mandatory for override and the event is archived in the audit timeline.

### 5. Importing new evidence (2 minutes)
- Go to the Import Center.
- Preview valid vs rejected rows.
- Confirm the visible banner: “SYNTHETIC DEMO DATA”.
- Explain batch history and import status states.

### 6. Rules administration (2 minutes)
- Open the Rules Administration page.
- Show rule-set list, draft vs published status, and a sample validation before publication.
- Explain the what-if simulation concept and why published versions remain immutable.

## Roles in the demo

- Demo lead: narrates the workflow and explains the business context.
- Reviewer: approves or overrides a recommendation.
- Administrator: demonstrates rule-set and import controls.
- Auditor: calls out the audit trail and decision traceability.

## Duration

Total planned session time: 15–20 minutes, depending on discussion and Q&A.
